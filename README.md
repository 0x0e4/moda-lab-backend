# Интернет-магазин Moda-Lab (backend)

**Учебный проект интернет-магазина**, разработанный в рамках дипломной работы. Здесь представлена backend-часть проекта, основным ЯП которого является TypeScript.

## Технологии
- **NestJS** — мощный и гибкий фреймворк для создания backend-приложений  
- **TypeORM** — фреймворк для работы с БД без написания SQL-запросов  
- **NestJS JWT** — фреймворк для аутентификации с использованием JWT на NestJS
